# Season 14 Alliance changes

Independent adaptation of [kvothed2/pd2-runewizard](https://github.com/kvothed2/pd2-runewizard), with visuals adapted from the owner's RotW Runewizard. The original license remains in LICENSE.

Added four runewords: **Finesse**, **Deception**, **Jealousy**, **Madness**.

These details are based on the October 2026 Season 14 beta recap and published runeword summaries. Final release verification is still necessary for changes to older runewords and any late tuning.

Jealousy is restricted to Amazon-specific throwing weapons; the existing Runewizard type system uses the broader Throwing Weapons category and calls out the restriction in item info. Do not use generic throwing bases.

GitHub Pages: Configure repository Settings → Pages → Build and deployment source: GitHub Actions. Vite's public base path is /pd2-runewizard/.
